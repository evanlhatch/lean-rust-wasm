Lean defines the types and policies. WASM components are the boundary.
Rust hosts them.

- **Proved schemas** — the spec of record is kernel-checked Lean; zero `sorry`.
- **Byte-tied codegen** — pure emitters fold the registry into WIT worlds,
  Rust types, Vortex dtypes; drift fails CI (`just gen-check`).
- **The dual-engine differential duel** — Lean's own evals are the oracle;
  the shipped wasm replays the manifest under wasmtime *and* wasmi.
- **WASIp3 components** — async functions, streams, resources at the WIT boundary.
